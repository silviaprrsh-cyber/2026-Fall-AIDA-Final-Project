- **Working workflow to demonstrate:** Open the [Windows research deployment guide](../courses/AIDA-2156/deployment/server/README.md). Identify the demo source as synthetic before showing its four latest flow tiles, one hourly rain tile and current/3-hour/9-hour estimate groups. Explain why an estimate is shown as unavailable when the required input has not arrived. A saved screenshot or table is a fallback if needed; it does not substitute for a live-data test.
- **Evidence supporting the conclusion:** Show the [historical V4 table](../courses/AIDA-2156/docs/MODEL_EXPERIMENTS.md): 27,256 historical rows, MAE 10.31 cm; the largest June episode's global peak was predicted on the wrong wave, 57h20 late. The primary June crest itself was underestimated by 9.21 cm at its actual timestamp. The dashboard demo uses a different source-only timing adapter with the frozen weights, not the historical test preparation.
- **Important limitation:** The proxy is not measured field depth, intermediate points are latent, and the data/model are not validated for flood alerts, emergency response or lead time. Neither cloud operation nor complete current monitoring is claimed.
