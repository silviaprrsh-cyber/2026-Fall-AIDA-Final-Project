# `segment_ml.json`

Defines minimum-point experimental zero and connected-channel selection, the two source profile mappings, and independent 05CC007 Q/stage/trend features. The empty 05CC007 section mapping is intentional. Its propagation lag and all segment coefficients use one joint endpoint training objective. Records time tolerances, initial lag and search range, trend window, chronological split, sample minimums and finite optimizer budget. Read by run.py ml. Configuration alone writes no files.
