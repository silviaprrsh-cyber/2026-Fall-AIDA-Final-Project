# Shared resources

Shared course utilities and configuration. `config/data_layout.json` locates course data and `config/archive_paths.json` resolves historical archive paths. [Migration verification](migration-verification.json.md) is retained as local evidence, not a statement about the contents of any final submission. The course research server, client and all deployment settings are separate; see the [AIDA 2156 deployment guide](../courses/AIDA-2156/deployment/server/README.md).
